# Gruenzeug

Pflanzen-Logbuch fürs Handy: **https://additiv3.github.io/gruenzeug/**

In Safari öffnen, dann *Teilen* → *Zum Home-Bildschirm*. Die App läuft komplett im Browser, auch offline,
und speichert alle Daten nur auf dem eigenen Gerät.

Dieses Repository enthält nur die gebaute App. Sie wird automatisch veröffentlicht.
